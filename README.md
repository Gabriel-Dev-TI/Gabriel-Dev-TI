## Sobre mim

Olá, eu sou **Gabriel José Alves do Couto**.

Sou estudante do **3º ano do Curso Técnico Integrado em Informática no IFMG — Campus Formiga**, com interesse em desenvolvimento de software e tecnologia.

Durante minha formação, venho trabalhando com diferentes áreas da computação, incluindo desenvolvimento de aplicações, banco de dados, redes e sistemas Linux.

Gosto especialmente de transformar ideias em projetos funcionais e de entender como as diferentes partes de uma aplicação se conectam.

Atualmente, um dos principais projetos que estou desenvolvendo é o **RotaJá**, uma plataforma voltada para gerenciamento e realização de entregas.

### RotaJá

**RotaJá** é um projeto desenvolvido durante minha formação em Informática.

A proposta é criar uma plataforma para **gerenciamento e realização de entregas**, conectando empresas e entregadores.

O projeto envolve diferentes partes do desenvolvimento de software, incluindo:

- Aplicação web
- Aplicação mobile
- API
- Banco de dados
- Autenticação
- Gerenciamento de entregas
- Geolocalização
- Rotas e mapas
- Integração entre diferentes tecnologias
